# PhoneXR v0.13 — Redmi 9 без меток

Бесплатная экспериментальная система для двух Android-телефонов **без ПК, наклеек и креплений к очкам**.

## Быстрый запуск

- **Redmi 13 (основной VR-интерфейс):** https://astsrotcreator.github.io/phonexr/?v=13
- **Redmi 9 (стационарная камера без метки):** https://astsrotcreator.github.io/phonexr/external-body.html

1. Оба телефона подключены к Wi-Fi и интернету. Открой оба адреса в **Chrome** по HTTPS, не через встроенный просмотр GitHub.
2. На Redmi 13 внизу настроек включи «Использовать внешнюю камеру Redmi 9» и оставь отмеченным «Без метки — отслеживать голову и плечи». Нажми «Создать код для Redmi 9».
3. На Redmi 9 введи полученный код, нажми «Соединить с PhoneXR», затем «Включить трекинг» и разреши заднюю камеру.
4. Закрепи Redmi 9 в стабильном положении, так, чтобы голова, плечи и по возможности корпус находились в кадре.
5. На Redmi 13 запусти PhoneXR, нажми «⌖ ЦЕНТР», находясь посередине зоны обзора Redmi 9.
6. Проверяй **без надетых VR-очков, сидя/стоя на одном месте**: медленно перемещай телефон/голову влево-вправо перед Redmi 9. Окна должны примерно смещаться противоположно. При потере человека окна скрываются.

## Как это работает

- `body-pose-worker.js` запускает облегчённый MediaPipe Pose Landmarker на Redmi 9 и обрабатывает кадры вне основного потока.
- Из нормализованных суставов вычисляются приблизительные координаты головы (или плеч при отсутствии лица), плеч и относительный размер фигуры.
- `external-body.html` передаёт только эти числа по WebRTC через PeerJS Cloud (интернет нужен для сопряжения; прямая связь зависит от сети).
- `index.html` на Redmi 13 строит приближённый **2D-сдвиг окон относительно исходной позиции тела**, а не реальные координаты комнаты. Координаты сглаживаются, резкие скачки отбрасываются.
- Никаких наклеек, распечаток или меток не нужно. Старый режим ArUco сохранён отдельно и по умолчанию не выбран.

## Главные ограничения

Это **НЕ AR 6DoF**. Стационарная камера видит тело в 2D и **не может точно определять поворот VR-очков или направление взгляда**. По нормализованному положению человека и размеру плеч невозможно надёжно вычислить положение глаз в трёхмерной комнате. При повороте спиной, уходе из кадра и перекрытии тела слежение может пропадать. Камера из одного угла не видит всю комнату.

Видеопросмотр Redmi 13 остаётся одноглазым видео, разделённым пополам; он не имеет настоящей стереоглубины. Задержки вычислений и WebRTC могут быть значительными.

**НЕ ИСПОЛЬЗУЙ PhoneXR для ходьбы по дому или обхода препятствий.** Проверяй функции без надетых очков, сидя, остановись при головной боли и головокружении.

## Файлы

- `index.html` — PhoneXR, интерфейс, камера VR, настройка связи.
- `external-body.html` — новый маркерлесс-режим внешней камеры Redmi 9.
- `body-pose-worker.js` — MediaPipe Pose Landmarker Lite.
- `external-tracking.js` — сопряжение по PeerJS и старые расчёты для ArUco.
- `external-camera.html`, `marker.html` — необязательный старый вариант с меткой.
- `hand-worker.js` — MediaPipe распознавание руки на Redmi 13.
- `vision-anchor-v11.js` — предыдущая экспериментальная 2D-привязка камеры.

Синтаксис и логика базовых вычислений проверены, **производительность и живое соединение Redmi 9 ↔ Redmi 13 пока не протестированы на устройствах**.
