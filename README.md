# PhoneXR v0.14 — Соединение Redmi 9 ↔ Redmi 13 через MQTT

Два Android-телефона без ПК и без меток: Redmi 9 следит за головой/плечами через MediaPipe, Redmi 13 показывает окна PhoneXR.

**Ссылки для новой версии:**

- **Redmi 13:** https://astsrotcreator.github.io/phonexr/?v=14
- **Redmi 9:** https://astsrotcreator.github.io/phonexr/external-body.html?v=14

## Исправление подключения

В предыдущей версии v0.13 пользователи могли получать «Ошибка PeerJS: Error». Эта ошибка не доказывает конкретную причину, но относится к установке связи, а не к камере или распознаванию тела. Поэтому v0.14 больше не использует PeerJS.

Оба телефона теперь подключаются к одному **публичному демонстрационному MQTT-серверу** `wss://broker.emqx.io:8084/mqtt` через защищённое соединение WebSocket. Для обмена используется случайный 12-значный шестнадцатеричный код и AES-GCM-шифрование сообщений. Ни один из телефонов не передаёт видео в сеть: только численные координаты головы, плеч и состояние трекинга. Поскольку сервер публичный, режим предназначен только для экспериментов, а не для защиты чувствительных данных.

1. Подключи оба телефона к интернету, желательно к одному Wi-Fi. Открой страницы в **Chrome**.
2. **Redmi 13:** в PhoneXR включи «Использовать внешнюю камеру Redmi 9», оставь «Без метки» и нажми «📡 Создать новый код для Redmi 9». Дождись **«✅ MQTT подключён»**, затем перепиши полученный **новый 12-символьный код**.
3. **Redmi 9:** открой страницу внешнего трекинга именно с `?v=14`. Введи новый код и нажми «Соединить с PhoneXR». Дождись статуса **«✅ Redmi 13 подключён!»**.
4. На Redmi 9 нажми «Включить трекинг», разреши заднюю камеру, дождись **«ТЕЛО ВИДНО»**.
5. На Redmi 13 запусти PhoneXR, нажми «⌖ ЦЕНТР». Проверяй осторожно, сидя, без надетых очков.

Если видишь **«Ошибка PeerJS»**, загрузилась старая версия страницы. Открой точные URL выше в новой вкладке Chrome; возможно, потребуется очистить кеш сайта. Старые 10-символьные коды больше не подходят.

Если сообщение **«MQTT подключён»** не появляется: убедись, что работают интернет и Wi-Fi, а соединения WebSocket на порт `8084` не блокируются. Публичный брокер может быть недоступен — автоматический доступ не гарантирован. Ошибка подключения отображается прямо на странице.

## Техническая схема

- `external-tracking.js`: зашифрованный MQTT-транспорт, генерация кода, отправка и приём сообщений, подтверждение соединения.
- `external-body.html`: страница Redmi 9, которая снимает видео локально, запускает worker и публикует только данные позы.
- `body-pose-worker.js`: облегчённый MediaPipe Pose Landmarker.
- `index.html`: PhoneXR, окна, трекинг рук, приём внешних координат и условная 2D-проекция.

Старый экспериментальный ArUco-режим сохранён как необязательная альтернатива: `external-camera.html` и `marker.html` (теперь с тем же MQTT-транспортом).

**НЕ используй этот прототип для ходьбы в VR-очках.** Внешняя камера без метки не определяет направление взгляда и не даёт настоящего 6DoF; видео Redmi 13 имеет задержку и не обеспечивает безопасный стереообзор.

### Проверка

- Проверены синтаксис основных JS-файлов и имитационный обмен: генерация кода, подключение к общей теме, подтверждение и доставка сообщения тела.
- Реальное подключение к публичному MQTT-серверу и распознавание на Redmi 9 **ещё не проверены** на устройствах.

Источники: [EMQX public broker](https://www.emqx.com/en/mqtt/public-mqtt5-broker), [MQTT.js](https://github.com/mqttjs/MQTT.js).
